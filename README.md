# Swiggy Data Analytics Project

## Overview
This project analyzes Swiggy food delivery data using Excel, Python, SQL, and Power BI to uncover restaurant performance, customer preferences, and business trends.

## Tools Used
- Excel
- Python (Pandas, NumPy)
- SQL
- Power BI

## Key Features
- Data Cleaning and Preprocessing
- SQL-Based Analysis
- KPI Tracking
- Interactive Dashboard
- Trend Analysis

## Problems Solved
- Handled missing values and duplicate records
- Corrected inconsistent data
- Fixed dashboard calculation issues
- Improved reporting accuracy

## Project Files
- swiggy_cleaned.zip
- swiggy_analysis.py
- swiggy_queries.sql
- Swiggy_Dashboard.pbix
